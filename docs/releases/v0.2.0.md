# vt-mcp 0.2.0

Existing URL, domain and IP intelligence joins file reports in the local VirusTotal MCP server.

- Add `get_url_report(url)`, `get_domain_report(domain)` and `get_ip_report(ip)`, backed by VTAI read-only lookups.
- Preserve source, actual analysis date, engine coverage and VirusTotal report links. Missing analysis dates stay null; retrieval time is separate.
- Keep existing file responses compatible, including older VTAI deployments without the new metadata.
- Apply bounded HTTP requests, sanitized errors and strict argument handling to all four tools. Unknown indicators never trigger scans.
- Provide Claude Code and Gemini CLI setup and a Python application example, with [client validation levels](../clients.md) recorded separately.

Full URLs, including query and fragment, are shared with VTAI and VirusTotal. Avoid secret URLs; query a domain when that scope is sufficient. Report text is untrusted evidence, not instructions. No result is a safety guarantee.

The added report tools require compatible VTAI endpoints. Version 0.2 uses local
stdio; remote MCP, new analyses, OAuth and BYOK are outside this version. These
historical notes do not imply that its assets are available from the current
channel. Use the [current installation guide](../../README.md#install-for-local-stdio).

To restore an older local installation, reinstall its previously verified wheel
and restart the client, keeping the existing protected credential file. Version
0.1 provides file queries only. A client reinstall does not roll back the service.
