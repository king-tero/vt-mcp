# vt-mcp 0.1.0

First local MCP integration for VirusTotal, powered by VTAI.

- Query an existing file report by MD5, SHA-1 or SHA-256 using `get_file_report`.
- Return structured evidence and a VirusTotal report link without reading or uploading files.
- Configure a VTAI credential outside the model, with bounded requests and sanitized errors.
- Install a versioned wheel and connect a stdio MCP client; Codex is the reference client.

The VTAI contract does not supply an analysis date. Unknown files and zero detections do not establish safety. This release does not include remote MCP, new analyses, URL/domain/IP tools, OAuth or BYOK.

These historical notes describe version 0.1; they do not imply that its assets
are available from the current distribution channel. Follow the [current
installation guide](../../README.md#install-for-local-stdio) and [client validation
matrix](../clients.md#validation-levels) for the selected version.
